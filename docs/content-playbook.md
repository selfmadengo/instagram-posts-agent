# Playbook de conteúdo — Instagram Selfmade

## 1. Estrutura base (SOP Brand-Kit)
**Gancho → Valor → CTA**

| Slide | Função | Layout recomendado |
|---|---|---|
| 1 | **Capa / gancho** — promessa ou contradição + objeto 3D | `cover` |
| 2–3 | Criar interesse com um exemplo (2.º gancho: o IG re-serve a partir do slide 2) | `statement`, `stat` |
| 4–5 | Reter atenção com diagramas | `compare`, `steps` |
| 6–9 | Informação prática | `list`, `steps`, `quote` |
| 10 | CTA simples | `cta` |

## 2. Formatos (SOP)
- **Comparação** (cenário bom vs mau) → `compare`
- **Tutorial** ("ensinar a fazer em 2 min") → `steps`
- **Vlog / POV** (mais pessoal) → Reel com vídeo real + legendas no ecrã
- **Compilação** (muita informação num post) → `list` em 8–10 slides
- **Histórias** (storytelling) → `statement` + `quote` (testemunhos reais e aprovados)

## 3. Pilares de conteúdo (proposta — validar)
| Pilar | % | Objetivo | Exemplos |
|---|---|---|---|
| **Oportunidades** (vagas Erasmus+, intercâmbios, formações, Corpo Europeu de Solidariedade) | 35 % | Leads / comentários | "3 vagas abertas para Itália", "Como entrar em 4 passos" |
| **Educação / mitos** (mobilidade, dinheiro, CV, idiomas, empreender) | 25 % | Guardados + partilhas | "O que pensas vs realidade", "5 erros na candidatura" |
| **Prova social** (histórias de participantes, antes/depois, bastidores) | 20 % | Confiança / gostos | Testemunho, POV "o meu 1.º intercâmbio" |
| **Empreendedorismo** (ideias, ferramentas, casos) | 15 % | Autoridade | "Começa um projeto com 0 €" |
| **Comunidade/local** (Fundão, parceiros, eventos) | 5 % | Relação | Recap de evento, agradecimento a parceiros |

## 4. Banco de ganchos (adaptar ao tema)
- **Contradição**: "Não é sorteio. Não é só para universitários."
- **Promessa + objeção**: "Viajar pela Europa *quase* de graça"
- **Número**: "5 erros que te tiram de um intercâmbio"
- **Pergunta direta**: "Tens entre 18 e 30 anos? Lê isto."
- **Antes/depois**: "Fui com medo de falar inglês. Voltei assim."
- **Segredo/insider**: "O que ninguém te diz sobre o Erasmus+"
- **Urgência real**: "Candidaturas fecham sexta" (só se for verdade)
- **Identidade**: "Se és do interior e queres sair, guarda isto"

## 5. CTAs (verbo + objeto)
- **Comentário com palavra-chave**: "Comenta EUROPA e enviamos-te as vagas" → ideal para automatizar DMs.
- **Partilha**: "Envia a quem precisa de sair da zona de conforto".
- **Guardar**: "Guarda para quando abrirem as candidaturas".
- **Seguir**: "Segue para receberes cada vaga primeiro".
- **Link**: "Candidata-te no link da bio".
Um CTA principal por post (+ guardar/enviar como secundário no slide final).

## 6. Legenda (template)
```
[1.ª linha = palavra-chave + gancho, ≤ 125 caracteres]
Erasmus+ para jovens: viajar pela Europa quase de graça (sim, existe) ✈️

[2–4 linhas de valor / contexto]

[CTA principal]
👉 Comenta EUROPA e enviamos-te as vagas abertas.

[Crédito UE quando aplicável]
Cofinanciado pela União Europeia.

#erasmusplus #intercambiodejovens #mobilidadeinternacional #fundao #juventude
```
- 3–5 hashtags específicas. Alt text sempre (descrever o slide 1 + tema).
- Português de Portugal, tratamento por "tu", frases curtas, sem jargão de programa.

## 7. Cadência (proposta)
- **3 posts de feed/semana**: 2 carrosséis + 1 Reel (ou 2 Reels + 1 carrossel em épocas de recrutamento).
- **Stories diárias** (sondagens, bastidores, repost de participantes, contagem decrescente para prazos).
- Testar ganchos com **Trial Reels** antes de publicar para todos.

## 8. Métricas (rever a cada 2 semanas)
| Métrica | Alvo inicial | Diz-nos |
|---|---|---|
| Swipe-through slide 1→2 | ≥ 60 % | Força do gancho |
| Skip rate Reels (3 s) | ≤ 50 % | Força do gancho |
| Envios / alcance | ≥ 1 % | Potencial de chegar a não seguidores |
| Guardados / alcance | ≥ 1,5 % | Valor útil |
| Comentários com palavra-chave | n.º de leads | Conversão |
| Seguidores por post | crescente | Crescimento |
Registar em `posts/<pasta>/resultados.md` 7 dias após publicar.
